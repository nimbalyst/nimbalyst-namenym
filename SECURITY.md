# Security

## Reporting a vulnerability

Use the repository's **Security → Report a vulnerability** feature for private reports once private vulnerability reporting is enabled. If that option is unavailable, use the security contact listed on [Nimbalyst's trust page](https://nimbalyst.com/trust/) to request a private reporting channel before sending sensitive details. Do not post credentials, private naming projects, or exploit details in a public issue.

Include the extension and Nimbalyst versions, affected feature, impact, and a minimal reproduction using synthetic data. There is no guaranteed response time. Security fixes target the latest released version; older versions do not have a separate maintenance branch.

## Scope

This repository contains the Namenym extension. The Nimbalyst host, AI providers, collaboration hosting, and domain lookup backend have separate implementations and security boundaries. See [PRIVACY.md](PRIVACY.md) for data flows. Domain availability is advisory and does not provide trademark clearance.
